# Курсовая работа №3

## Описание проекта

Проект представляет собой систему для сбора, хранения и анализа вакансий с платформы HeadHunter. Приложение позволяет:

- Получать данные о вакансиях с сайта hh.ru через публичное API
- Хранить информацию в PostgreSQL базе данных
- Анализировать данные о вакансиях и работодателях
- Искать вакансии по ключевым словам

## Функциональность

### Основные возможности:

- Сбор данных о 10 компаниях-работодателях:
  - Яндекс
  - Сбербанк
  - Т-Банк
  - EFT GROUP
  - Правительство Москвы
  - Анвио Парк
  - X5 Tech
  - ИП Фомин Сергей Александрович
  - ООО Антара
  - Красное & Белое

- Хранение данных в PostgreSQL:
  - Таблица `employers` для информации о работодателях
  - Таблица `vacancies` для вакансий с привязкой к работодателям

- Класс DBManager для работы с базой данных:
  - `get_companies_and_vacancies_count()` - список компаний и количество вакансий
  - `get_all_vacancies()` - все вакансии с деталями
  - `get_avg_salary()` - средняя зарплата по вакансиям
  - `get_vacancies_with_higher_salary()` - вакансии с зарплатой выше средней
  - `get_vacancies_with_keyword()` - поиск вакансий по ключевому слову

## Установка и запуск

### Требования

- Python 3.14 или выше
- PostgreSQL
- Библиотеки: psycopg2, requests

### Установка зависимостей

```bash
pip install psycopg2 requests
```

### Настройка базы данных

1. Создайте файл `database.ini` в корне проекта:
```ini
[postgresql]
host=localhost
port=5432
database=coursework3
user=postgres
password=ваш_пароль
```

2. Запустите приложение:
```bash
python main.py
```

Приложение автоматически создаст базу данных и таблицы при первом запуске.

## Использование

При запуске приложения выполняются следующие шаги:

1. Создание/подключение к базе данных
2. Создание таблиц `employers` и `vacancies`
3. Заполнение базы данных данными о компаниях и их вакансиях
4. Демонстрация работы методов DBManager
5. Интерактивный режим для поиска вакансий
